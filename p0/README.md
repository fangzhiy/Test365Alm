# P0 执行资料

本目录把 S01～S03 的输入、范围冻结和风险证据要求落成可填写的工作资料。当前资料只记录已知事实、待确认事项和证据要求，不把规划文档或示例数据当作客户环境验证。

## 当前状态

- 阶段：P0，等待 G0 范围评审
- 业务应用：尚未实现
- 目标 ALM 版本、Edition、扩展、客户端和样本：待授权确认
- 兼容性、迁移、性能和安全结论：NOT_RUN

## 使用顺序

1. 由产品负责人和领域专家填写 `environment-ledger.csv`，每个决策项附版本、授权或会议证据。
2. 由产品负责人维护 `scope-baseline.md`，所有未知项保持 `OPEN`，不得默认为不适用。
3. 获得三类脱敏项目后，填写 `golden-dataset-manifest.json`，为每个输入保存来源、授权、数量和 SHA-256。
4. 迁移负责人依据真实提取结果维护 `migration-gap-report.md`，无法提取的对象必须逐项说明去向。
5. 兼容负责人将实测请求、事件轨迹和差异链接回 `planning/compatibility-matrix.csv`。

## 证据规则

- 不写入客户密码、令牌、个人信息或业务附件。
- 示例 UUID、空哈希和 `MISSING_INPUT` 只能表示待输入，不能用于关闭验收。
- 每条结论都要能回到授权记录、原始样本、重现命令或独立复核结果。
- 没有目标环境或合法样本时，状态保持 `OPEN` 或 `BLOCKED`。
