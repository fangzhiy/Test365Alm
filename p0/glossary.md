# P0 核心术语表

这些定义用于范围评审、数据建模和验收用例。目标产品行为仍需结合真实环境和签批范围确认。

| 术语 | 定义 | 不允许的混淆 |
|---|---|---|
| Requirement | 业务或产品要求的稳定实体，内容通过不可变修订表达 | 不能直接等同于测试用例或运行结果 |
| RequirementRevision | Requirement 在某一时刻的内容快照，可进入评审和批准状态 | 已批准修订不能原地覆盖 |
| Test | 可复用的测试定义和稳定身份 | 不能与某次执行混为同一对象 |
| TestRevision | 测试步骤、参数和规则在某一时刻的版本 | 修改不会重写历史运行引用 |
| TestInstance | 测试在测试集、发布或配置中的执行实例 | 不是 Test 的另一个可变名称 |
| Run | 一次有固定 manifest 的运行，保存范围和执行事实 | 不能每次展示时读取当前 Test |
| Attempt | Run 中一次独立的执行尝试，拥有租约和结果证据 | 重试不能覆盖旧 Attempt |
| RunStep | 某次 Attempt 对单个步骤的结果和证据 | 基础设施故障不能伪装成断言失败 |
| Baseline | 一组实体、关系和资产修订的闭包快照 | 不能只给当前数据打标签 |
| AssetRevision | 附件或测试资源的不可变内容版本及哈希 | 不能让运行隐式指向 latest |
| TraceLink | 两个稳定实体或修订之间的带作用域关系 | 不能用自由文本绕开权限和完整性 |
| OutboxEvent | 与业务写入同事务提交的待发布事件 | 不能依赖事务提交后的临时内存通知 |
| MigrationJob | 有来源指纹、映射版本和检查点的数据迁移批次 | 不能用一次性脚本跳过对账和隔离 |

## 评审规则

任何新增术语必须说明稳定身份、修订语义、权限作用域、历史保留和与现有对象的关系。没有实际行为证据的定义标记为“设计建议”，不能写成兼容事实。
