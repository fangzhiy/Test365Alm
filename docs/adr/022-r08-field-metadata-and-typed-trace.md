# ADR 022：项目字段定义与需求→用例关系第一切片

状态：已实施，验收证据见本轮执行记录；不等于完整 M04/M11 验收。

## 决策

- 沿用当前 OIDC 会话、ProjectService 动态授权、受限 runtime、事务本地租户/项目/主体上下文和 RLS。不引入新的身份系统。
- 正式 V17 仅新增字段定义/不可变定义修订、typed 追踪关系/失效历史及这两个切片共用的幂等与 Outbox。V1—V16 不修改；专用故意失败探针顺延 V18。
- 自定义字段稳定 UUID/key/type；定义变化只追加修订。SYSTEM 为既有系统保留字段的只读目录，本轮不将自定义值写入需求、用例或执行记录，更不回填历史。
- TEXT 按 Unicode code point 限长；NUMBER 用精确十进制字符串与 BigDecimal，不接受浮点强制转换；ENUM 与默认值使用同一服务验证。导入/同步/脚本入口未交付，不宣称已使用共享验证。
- 字段写入要求有效 PROJECT_ADMIN；关系写入要求有效 PROJECT_MEMBER/ADMIN。VIEWER 只读/验证；失权不因旧幂等键绕过重新授权。
- 关系端点是真实同租户/项目的 requirement/test_case 及其确切修订复合 FK，不采用通用无约束对象字符串。同端点最多一条有效关系，失效不物理删除历史。
- 幂等按租户/项目/主体/路由/key，24 小时；项目级事务锁串行化并发命令，冻结响应及长度编码摘要。业务、修订、审计、Outbox、幂等同事务，故障后完整回滚。
- 覆盖采用同步授权单需求数据库汇总，不伪称异步投影。只有关联绑定修订仍为需求/用例当前修订、最新已完成确切源修订 PASS 且无活动尝试才计入 passedTests。未执行为 0；关联数是分母，不等于 PASS。
- 本轮没有用例归档/删除 API，不能宣称已测试不存在的用例停用能力；已删除需求、缺失或跨范围端点拒绝。
- 页面保持范围重挂载与请求代次、取消、8 秒有界超时；未知写入保留原快照/原 key 重试，锁定输入，不自动换 key 或自动覆盖版本冲突。

## 边界与验证

不实施动态表单设计器、字段值迁移、完整实体注册、suspect、watermark、需求影响传播或运行→缺陷关系。
真实 PostgreSQL、OIDC HTTP、Vitest、Keycloak 页面及名称门禁的实际提交和结果由 `docs/progress/runs/R08-CORE-BATCH01.md` 记录。规划 PLANNED/NOT_RUN 不改变。
