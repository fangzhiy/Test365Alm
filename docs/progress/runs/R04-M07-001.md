- 新增 Flyway `V7__requirements_slice.sql`：项目作用域 allocator、`requirement`、append-only `requirement_revision`、`requirement_idempotency`、`outbox_event`，复合外键、RLS、运行时列级 grants 和 requirement audit policy；不改写 V1-V6。

- 新增后端 Controller 单元和真实 PostgreSQL `RequirementDatabaseIT`（创建编辑历史、viewer 边界/过期版本、幂等冲突）；CI 增加报告门禁 `tools/verify_r04_requirement_report.py`。
- 新增 `RequirementsPanel`、API 解析和测试，接入已选项目上下文；支持列表/空态/创建/详情/编辑/只读历史、412 草稿保留、项目切换/退出清理、AbortController/超时/请求轮次。前端请求使用同源 cookie、CSRF 和 Idempotency-Key/If-Match。
- 新增 `contracts/requirements.json`，并更新 `contracts/openapi-core.json`；增加 ADR-013。README/AGENTS 记录真实命令、边界和本机 Docker 限制。CI 浏览器门禁增加真实 Keycloak 需求 UI 流程。
