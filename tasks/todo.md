- **证据与验证：** `environment-inventory`、授权记录、版本截图/导出、决策表；由 QA 抽查来源与权限，不接受只引用 26.1 文档代替真实环境。
- **阻塞：** B01；W01 末仍无目标版本时升级到项目负责人，W02 末仍无答复则在 G0 作为调整项。

### P0-04 工程骨架、版本锁和可复现健康检查

- **动作：** 建立 `apps/web`、`apps/server`、`apps/worker`、`agents`、`compat`、`db/migration` 和 `tests` 目录；验证 Java/Spring Boot、Node/React、PostgreSQL 等候选版本；加入健康检查、格式/类型/单测、Flyway 迁移、契约检查和凭据扫描。
- **验收：** M02-AC01～M02-AC05；空机器按 README 可构建健康检查；空库和上一版本迁移均可执行；非法跨模块依赖可被架构检查阻止；失败流水线不发布或触碰生产。
- **证据与验证：** 构建 SHA、锁文件、镜像摘要、迁移日志、CI 日志、SBOM、回滚记录；独立开发机复跑一次。
- **阻塞：** B08；候选依赖只在验证后锁定，不能使用 `latest`。

### P0-05 威胁模型、许可和组件分发审查

- [ ] **负责人：** 安全负责人 + 授权负责人；**工作流：** E；**依赖：** P0-01
- **动作：** 识别跨租户、附件、脚本、节点凭据、对象存储和支持包风险；审查 REST/OTA/COM/脚本 SDK、运行时、扫描器和镜像许可；登记独立实现边界与不可分发组件。
- **验收：** 威胁模型覆盖 API、搜索、报表、导出、附件、执行节点和 AI 入口；许可/分发结论有来源；高危问题有阻断规则。
- **证据与验证：** 威胁模型、许可清单、SBOM 草案、数据分级和密钥处理约束；安全负责人签字，不能用“内部使用”替代授权结论。
- **阻塞：** B04、B07；许可不清的组件不得进入兼容承诺或发布计划。

## W02：工程试建与核心风险样本

- **动作：** 抽样验证至少 10 个项目 REST 调用，覆盖认证、字段、查询、分页、锁、附件、空值和错误；保存请求/响应、状态码、头、Cookie、时间和真实持久化结果；与新平台概念验证比较。

### P0-07 OTA/COM/VBScript/客户端实验室

- **动作：** 抽样验证至少 3 个 OTA 程序、3 段 VBScript，并覆盖 32/64 位、对象枚举、连接释放、事件顺序、错误返回、字段副作用；保留 VM 快照、安装包哈希、授权记录和卸载影响。

### P0-08 基线、manifest 和并发一致性概念验证

- [ ] **负责人：** 迁移负责人 + 数据工程师；**工作流：** C；**依赖：** P0-03、合法提取方式
