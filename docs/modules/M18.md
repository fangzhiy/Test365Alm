# M18 外部系统集成与开发追踪

阶段：P2/P3。责任角色：集成工程师。当前状态：PLANNED。

## 输入与依赖

完整模块依赖：M10、M11、M13、M16。这里表示最终集成依赖；预研或早期最小切片可先行。开始具体 Issue 前，须声明所依赖接口、数据约束和切片版本，不能把尚未开发的依赖假装可用。

准备签批范围、授权样本、角色矩阵和适用基线；将未满足条件登记为 BLOCKED，不伪造输入。

## 领域对象与拟定接口

领域对象：`connector`、`credential_reference`、`external_mapping`、`inbox_event`、`sync_cursor`、`build_link`、`change_link`。

- `POST /api/v1/projects/{projectId}/connectors`
- `POST /api/v1/webhooks/{connectorId}`
- `POST /api/v1/projects/{projectId}/connectors/{connectorId}/reconcile`

## 按顺序实施

### M18-T01

建立连接器清单：GitHub、Jenkins、Jira、Azure DevOps、消息协作、测试工具及已授权许可服务；每个连接器冻结版本、方向、字段所有权和最低权限。

### M18-T02

外部凭据交给密钥管理，连接测试只执行无副作用读操作；Webhook 校验签名、时间窗与重放 ID，记录 inbox 后立即应答。

### M18-T03

双向同步使用 external_mapping 和各侧修订；定义字段主权及人工冲突队列，禁止用最后写入静默覆盖全部字段。

### M18-T04

关联需求/缺陷、提交、拉取请求、构建与部署；使用稳定外部 ID，不通过模糊文本匹配直接建立确定关系。

### M18-T05

实现速率限制、指数退避、死信、游标回补和全量对账；外部删除通过 tombstone 及审批传播，避免连锁删除历史证据。

### M18-T06

为 LoadRunner 项目定义独立执行任务及结果摘要协议：ALM 存索引和质量结论，性能平台存采样及大体量时序数据。

## 验收与负向测试

**M18-AC01：** 重复 Webhook 不会重复创建缺陷或运行记录。

**M18-AC02：** 伪造签名及超出时间窗的事件被拒绝并审计。

**M18-AC03：** 两侧同时修改受控字段进入冲突队列而不是静默丢失。

**M18-AC04：** 外部 API 限流后重试可恢复且不会阻塞主交易。

**M18-AC05：** 外部凭据撤销后及时停止同步，界面提示原因但不泄露令牌。
