# M16 自动化执行与测试引擎适配

阶段：P1/P2。责任角色：执行引擎工程师。当前状态：PLANNED。

## 输入与依赖

完整模块依赖：M05、M08、M09、M13。这里表示最终集成依赖；预研或早期最小切片可先行。开始具体 Issue 前，须声明所依赖接口、数据约束和切片版本，不能把尚未开发的依赖假装可用。

准备签批范围、授权样本、角色矩阵和适用基线；将未满足条件登记为 BLOCKED，不伪造输入。

领域对象：`agent`、`agent_capability`、`execution_job`、`lease`、`run_attempt`、`result_chunk`、`adapter_manifest`。

- `POST /api/v1/agent-enrollments`

## 按顺序实施

### M16-T01

定义 Runner Adapter SPI：validate、prepare、start、poll、cancel、collect；每个适配器声明支持系统、引擎版本、参数、许可证和结果语义。

### M16-T02

执行节点使用一次性注册令牌换取短期证书或受限凭据；能力标签仅在管理员审核后参与调度，任务参数不允许任意越权命令。

### M16-T03

调度器以原子领取和租约分配任务，生成 fencing_token；旧租约的心跳及结果拒收，重试产生新 attempt 而不是覆盖旧 attempt。

### M16-T04

节点在隔离工作目录准备资产，按白名单启动进程或容器；保存任务 ID 与本地进程映射，实现可恢复取消、超时及断线续传。

### M16-T05

结果分块带序号和哈希，去重后归档；区分测试失败、基础设施失败和未知状态，未知副作用任务禁止自动重复执行。

### M16-T06

先接入 JUnit XML 结果与一种可用开源执行器，再接入合法授权的 UFT/LoadRunner 等目标清单；真正执行引擎能力不计为本平台已自研。

## 验收与负向测试

**M16-AC01：** 两台节点同时领取任务仅有一台获得有效租约。

**M16-AC02：** 过期节点回传 PASS 被拒绝，不覆盖有效新尝试。

**M16-AC03：** 断网后重复上传结果块不产生重复步骤和附件。

**M16-AC04：** 取消任务后残留子进程被终止或明确报告人工处置。

**M16-AC05：** 存在外部副作用且结果未知的任务被置为待人工核对，不盲目重跑。
