## 实施内容

- `apps/server` 集成测试改用锁定 `org.testcontainers:testcontainers-postgresql` 和 JUnit Jupiter `2.0.5`，目标库与对照库均由测试创建；不读取日常 `.env`。
- `PlatformDatabaseIsolationIT` 在目标临时库执行删表故障注入，并在独立对照库保存两条数据、验证两条数据未改变；不再通过 finally 插回共享库默认记录。
- `tools/verify_r02_readiness.py` 使用专用 env、唯一 Compose 项目、PID/版本提交/容器标签身份、启动日志、端口预检、超时和严格监听检查；支持 IPv4、IPv6、IPv4-mapped IPv6 回环，无法枚举或归属不明失败；只清理本轮确认拥有的资源。
- `tools/verify_r02_migration_failure.py` 在临时 filesystem V2 位置注入明确失败迁移，独立 JVM 必须非零退出并在脱敏日志中识别 Flyway V2；正式迁移目录不变。
- `apps/web/src/App.tsx` 同时检查健康响应 HTTP 状态和响应字段；HTTP 500/503 不显示正常，合法 readiness 503 保留诊断，矛盾字段不显示全正常；新增 3 个前端回归场景。
- CI 移除集成测试对共享 service PostgreSQL 的依赖，改由 Testcontainers；加入迁移失败 job、检出 SHA、stderr 报告、缺报告失败和仅失败时 `::error`。
- README、AGENTS 和 ADR-008 更新测试/开发边界与故障注入规则。
