完整模块依赖：M01、M13、M20、M24。这里表示最终集成依赖；预研或早期最小切片可先行。开始具体 Issue 前，须声明所依赖接口、数据约束和切片版本，不能把尚未开发的依赖假装可用。

## 按顺序实施

### M25-T01

在隔离 Windows 实验室获取合法 SDK 与样本；登记 x86/x64、类型库、ProgID、事件、对象工厂、集合、异常和客户端版本，不在主开发机覆盖厂商组件。

### M25-T02

通过独立实现的 COM 外观与进程外桥接保持接口对象生命周期；验证枚举器、可选参数、VARIANT、日期和错误码。是否可使用原标识须经许可审查。

### M25-T03

为高频 OTA 对象逐个映射原生 API，保存对象缓存与提交边界；明确 Post/Refresh/Lock 等语义，禁止只把方法名转为 HTTP 路径。

### M25-T04

脚本兼容实现事件调度、模板/项目调用顺序、共享变量和错误语义；允许的对象能力由白名单控制，脚本不得默认获得文件系统或网络管理权限。

### M25-T05

针对 Excel 宏、自定义测试类型、站点管理 COM、插件和原客户端分别运行原样本；无法无修改兼容的样本记录改造清单和工作量。

### M25-T06

签名安装包、隔离注册、卸载及并存回归；保持新平台原生模型独立。最终无样本或无合法实现路径的项维持未验收，升级治理而非默默排除。

## 验收与负向测试

**M25-AC01：** 32 位和 64 位样本在对应环境可安装、枚举对象和释放连接。

**M25-AC02：** 原脚本的事件顺序、错误返回和字段写入副作用符合冻结契约。

**M25-AC03：** 恶意脚本不能突破配置的进程及网络边界。

**M25-AC04：** 兼容组件卸载后不破坏原厂客户端合法安装。

**M25-AC05：** 零修改兼容声明均有真实旧程序、版本和运行日志证据。
