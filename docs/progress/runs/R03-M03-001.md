## 实际改动及原因

- `docs/adr/010-r03-oidc-session-slice.md`、`contracts/identity-session.json`：冻结本轮 OIDC/会话边界、固定回调、API 形状与未实现能力。

- `apps/server/pom.xml`、`application-oidc.properties`、`V2__principal.sql`、`identity/`：沿用 Boot 4.1.1 BOM 的 Security 7.1.1，正式迁移建立唯一 `(issuer, subject)` 主体；Spring Security 标准 OIDC Code+PKCE、BFF HttpSession、CSRF、受保护 `/me` 和本地退出。无 IdP 配置时业务身份 API 拒绝访问，探针保留。
- `apps/web/src/AuthPanel*`、`App.tsx`、Vite 代理、Playwright 测试：显示真实登录/未登录/失败/停用状态，经过 Keycloak 授权码回调获取 `/me`，退出先取得 CSRF。R02 健康工作台未重做。
- `PlatformDatabaseIT`、`PrincipalUpgradeIT`、身份单测、Python 配置测试、`.github/workflows/ci.yml`：覆盖并发稳定身份、V1→V2、最小权限、负向 API、真实浏览器链路；CI 保留五个 R02 job 并加认证浏览器 job。
- `tools/verify_r02_migration_failure.py` 与测试：正式 V2 后将测试专用故意失败迁移移至 V3，并要求专属 SQL 错误标记，不能用版本冲突冒充迁移失败。
- `README.md`、`AGENTS.md`、本状态记录：写明本机启动、停止、开发/CI 偏差和未验证项。原 R02 记录保持历史事实。
